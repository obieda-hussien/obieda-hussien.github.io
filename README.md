# React Project (obieda-hussien.github.io)

A modern web application built with **React**, **Vite**, and **ESLint**.

---

## 📋 Prerequisites

Before running the project, make sure you have:

* **Node.js** (LTS version recommended)
* **npm** (comes bundled with Node.js)

Check your installation:

```bash
node -v
npm -v
```

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/obieda-hussien/obieda-hussien.github.io.git
```

### 2. Navigate to the project folder

```bash
cd obieda-hussien.github.io
```

### 3. Install dependencies

```bash
npm install
```

This command installs all required packages listed in `package.json`.

### 4. Start the development server

```bash
npm run dev
```

After the server starts, open the URL shown in the terminal (typically):

```
http://localhost:5173
```

The project supports **Hot Module Replacement (HMR)**, so changes are reflected instantly while developing.

---

## 📦 Available Scripts

| Command           | Description                                                    |
| ----------------- | -------------------------------------------------------------- |
| `npm run dev`     | Starts the development server.                                 |
| `npm run build`   | Creates an optimized production build in the `dist` folder.    |
| `npm run preview` | Serves the production build locally for testing.               |
| `npm run lint`    | Runs ESLint to check code quality and detect potential issues. |
