# Obieda Hussien — Portfolio

Personal bilingual (Arabic/English) portfolio built with React and Vite.

- Presents only selected **public** repositories: OmniLink SDK, Omni AndroidIDE, and Omni Launcher.
- Does not list private projects, proprietary internals, download counts, or unverified metrics.
- Responsive dark-purple design with an accessible language toggle and reduced-motion support.
- Business inquiries link to Codenetra, rather than exposing a personal phone number here.

## Develop

```bash
npm ci
npm run dev
```

## Check & build

```bash
npm run lint
npm run build
```

The production site is built into `dist/`. GitHub Pages must be configured to publish the site's build output or a Pages Actions workflow; the Vite source files are not themselves the published site.
